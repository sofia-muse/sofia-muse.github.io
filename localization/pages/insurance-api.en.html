Engineering decisions

Safe retries

Issue and cancel endpoints accept an idempotency key. The same key and payload replay the original result; a changed payload returns a conflict.

Rules at two levels

A customer can have at most one active car policy. Service checks and a filtered unique SQL index both enforce that rule.

Concurrent changes

A row-version token detects stale policy updates, returning a conflict instead of silently replacing another change.

Traceable lifecycle

Issuing, updating and cancelling policies create audit events. Cancellation retains the record, and cancelled policies cannot be updated.

JWT-protected writes · rate limiting · xUnit testsPersonal project

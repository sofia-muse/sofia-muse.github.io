CASE STUDY

Life RPG

A habit-building app with character creation, quests and visible progress.

The task

Turn everyday habits into quests with a character, rewards and visible progress.

My role

A personal application project with a React Native / Expo interface and a .NET backend. This case demonstrates the local interface flow.

The solution

Create a character, choose starter quests, claim a daily reward and complete a quest to update progress.

See it in action

Evidence & limitations

Onboarding, the daily reward and quest completion were checked in the built-in local demo. Cloud sync, server authentication and AI services were not verified by these screens.

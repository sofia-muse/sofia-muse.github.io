החלטות הנדסיות

בקשות חוזרות בטוחות

נקודות הקצה להנפקה ולביטול מקבלות מפתח אידמפוטנטיות. אותו מפתח ואותם נתונים מחזירים את התוצאה המקורית; נתונים שונים מחזירים שגיאת התנגשות.

כללים בשתי שכבות

ללקוח יכולה להיות לכל היותר פוליסת רכב פעילה אחת. הכלל נאכף גם בבדיקות בשירות וגם באינדקס SQL ייחודי מסונן.

עדכונים במקביל

טוקן גרסת רשומה מזהה עדכונים מיושנים לפוליסה ומחזיר שגיאת התנגשות במקום לדרוס שינוי אחר ללא התרעה.

מחזור חיים שניתן לעקוב אחריו

הנפקה, עדכון וביטול של פוליסות יוצרים אירועי ביקורת. ביטול שומר את הרשומה, ולא ניתן לעדכן פוליסה שבוטלה.

Insurance Management API

Бизнес-правила и предсказуемая запись данных в личном API на .NET.

Задача

Управлять клиентами и жизненным циклом полисов, обрабатывая повторные запросы и конфликтующие изменения.

Моя роль

В этом личном проекте я реализовала backend, бизнес-правила и тесты API.

Решение

API на .NET 8 для управления клиентами и жизненным циклом полисов автострахования, здоровья и жизни. Бизнес-правила, предсказуемые ошибки и надёжная запись данных.

Устаревшие записи и конфликтующие запросы возвращают понятные ошибки.

Технические решения

Безопасные повторы

Эндпоинты выпуска и отмены принимают ключ идемпотентности. Тот же ключ и данные возвращают исходный результат; изменённые данные вызывают конфликт.

Правила на двух уровнях

У клиента может быть не более одного активного автомобильного полиса. Это правило защищают проверки сервисов и фильтрованный уникальный индекс SQL.

Параллельные изменения

Токен версии строки выявляет устаревшие обновления полиса: возвращается конфликт вместо незаметной перезаписи чужого изменения.

Прослеживаемый жизненный цикл

Выпуск, обновление и отмена полисов создают события аудита. При отмене запись сохраняется, а отменённый полис нельзя изменить.

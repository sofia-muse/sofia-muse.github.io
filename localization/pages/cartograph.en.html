CASE STUDY

Cartograph

A developer tool for exploring C#, SQL and Umbraco dependencies before making a change.

The task

Before changing a legacy system, understand which C# methods, SQL procedures and CMS elements depend on one another.

My role

A personal developer-tool project connecting indexing, a searchable graph and a web interface.

The solution

Roslyn, T-SQL parsing and Umbraco/uSync indexing feed a SQLite graph. The dashboard and MCP tools expose search, call sites and impact information.

See it in action

Evidence & limitations

The local LegacyShop sample produced 102 nodes and 119 relationships. These are demonstration counts, not business-impact metrics. The preview ran without an AI service; external MCP integration and cloud chat were not tested.
